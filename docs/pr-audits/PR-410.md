## Audit Findings & Fixes Applied

1. **Ported Onto Slideflow 3.1.0 MIL Architecture (`TrainerConfig` & `BagDataset`)**:
   - Upstream PR `#410` targeted legacy `TrainerConfigFastAI` and `_build_fastai_learner` prior to Slideflow 3.x's `TrainerConfig` / `MILModelConfig._build_dataloader` refactor.
   - **Resolution**: Added `balanced: bool = False` to `TrainerConfig` and wired `balanced` into `TrainerConfig.build_train_dataloader` and `data.build_dataset`.
2. **Zero-Length Bag `NaN` Prevention (`_to_fixed_size_bag`)**:
   - When `len(bag) > bag_size`, integer floor division `bag_size // len(bag)` previously evaluated to `0`, producing an empty `0`-length bag (`NaN` attention softmax).
   - **Fix**: Clamped `per_slide = max(1, ...)` with `[:bag_size]` cap, preserved `dtype` & `device` on zero-padding, and ensured `preload=True` preserves per-slide sublists when `balanced=True`.
3. **Validation DataLoader Compatibility**:
   - Ensured `BagDataset.__getitem__` concatenates slide lists cleanly when `bag_size=None` or `max_bag_size` is set.
4. **Added `nystrom-attention` Dependency & Regression Tests**:
   - Added `nystrom-attention` to `setup.py` `extras_require['torch']` (for `TransMIL`) and added `test_pr410_balanced_bags_patient_mil`.

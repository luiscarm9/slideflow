## Audit Findings & Fixes Applied

1. **Private `scikit-learn` `_BaseEncoder._check_X` Dependency in `OrdinalClassEncoder`**:
   - Replaced private `sklearn.preprocessing._encoders._BaseEncoder` inheritance with a clean public NumPy implementation returning `float32` `(n_samples, k-1)` threshold matrices and `.categories_`.
2. **FastAI Validation Metric Crash (`RocAuc()` vs Ordinal Sigmoid Thresholds)**:
   - Single-label Softmax `RocAuc()` fails on 2D binary threshold targets `(B, k-1)`. Added a safe multi-threshold sigmoid `_ordinal_roc_auc` `AccumMetric` for `model_type == 'ordinal'`.
3. **Missing Ordinal Prediction Conversion in `eval_mil()` (`slideflow/mil/eval.py`)**:
   - Upstream PR `#441` updated `_train_mil()` to call `utils.create_preds(df)` and `categorical=True`, but missed `run_eval()` in `slideflow/mil/eval.py:824`, causing `eval_mil()` to fail when computing `classification_metrics`. Fixed `eval.py` to convert ordinal logits via `create_preds` before `rename_df_cols` / `run_metrics`.
4. **2-Class (`k=2`, `n_bits=1`) Target Squeeze Safety (`slideflow/mil/data.py`)**:
   - Changed `targets.squeeze()` → `targets.squeeze(0)` so `(1, 1)` targets keep feature dimension `(1,)` rather than collapsing to 0-D scalars.
5. **Added Regression Tests**:
   - Added end-to-end `test_pr441_mil_ordinal_training_and_eval` verifying `train_mil(loss='BCE_ordinal')` and `eval_mil()` across 3 ordinal grades.

# Audit Report — Upstream PR #444 (`Multimodal models`)

- **Upstream URL**: https://github.com/slideflow/slideflow/pull/444
- **Upstream Branch**: `slideflow:multimodal` → `master` (1 commit, 2 files)
- **Original Author**: `ldonle`
- **Fork Audit Branch**: `pr-audit/444-multimodal`

## Audit Findings & Fixes Applied

1. **Missing Model Registration (`@register_model`)**:
   - Upstream PR `#444` exported `Attention_IM_MIL` in `slideflow/mil/models/__init__.py` without registering it in `slideflow/mil/__init__.py`, preventing instantiation via `sf.mil.mil_config("attention_im_mil", ...)`.
   - **Fix**: Registered `attention_im_mil` in `slideflow/mil/__init__.py`.
2. **Shape Mismatch Crash in `calculate_attention` & `get_last_layer_activations`**:
   - `self.encoder` takes `n_feats - clinical_num_features` image features, whereas `calculate_attention` and `get_last_layer_activations` passed full unsliced `bags` (`n_feats`) into `self.encoder(bags)`.
   - **Fix**: Added `_split_features(bags)` and used `non_clinical_features` consistently across `forward`, `calculate_attention`, and `get_last_layer_activations`.
3. **Zero-Slice Edge Case (`clinical_num_features <= 0`)**:
   - Default `clinical_num_features=0` evaluated `bags[..., :-0]` (`bags[..., :0]`, empty tensor!).
   - **Fix**: Added explicit validation `0 < clinical_num_features < n_feats`, normalized CRLF line endings to LF, and added `test_pr444_multimodal_attention_im_mil`.

## Audit Findings & Fixes Applied

1. **`Dataset.labels(..., use_float=True)` Scalar Subscript Crash in `utils.get_labels`**:
   - When `outcomes` and `events` are single strings (e.g., `outcomes="time"`, `events="event"`), `dts.labels(..., use_float=True)` returns scalar `float` values rather than 1-element lists, causing `time_labels[slide][0]` to raise `TypeError: 'float' object is not subscriptable`.
   - **Fix**: Normalized both scalar and sequence label outputs safely and preserved backward-compatible `bool` `model_type` / `categorical=` keyword support in `get_labels` and `rename_df_cols`.
2. **Autograd Graph Preservation on Fully-Censored Mini-Batches (`CoxProportionalHazardsLoss`)**:
   - Replaced disconnected `torch.tensor(0.0, requires_grad=True)` with `log_h.sum() * 0.0` when `events.sum() == 0`.
3. **2D Tensor Shape & Admissible-Pair Guard in `c_index` (`slideflow/stats/concordance.py`)**:
   - Flattened `y_pred` (`(N, 1)` → `(N,)`), added PyTorch tensor `.detach().cpu().numpy()` conversion, and caught `ZeroDivisionError` when a validation fold lacks uncensored admissible pairs.
4. **Survival Sign Convention Verified**:
   - Verified `CoxProportionalHazardsLoss` outputs log-hazard `log_h`, training `c_index` negates `-y_pred`, and `predict_mil` stores `-log_h` in `y_pred0` (`time-y_pred`) matching `slideflow.stats.metrics.concordance_index` (higher score = longer survival).
5. **Added Regression Tests**:
   - Added `test_pr447_mil_survival_training_and_eval` verifying `train_mil(loss='CPH', outcomes='time', events='event')` and `eval_mil()`.

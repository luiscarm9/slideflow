## Audit Findings & Hardening Applied

1. **Restored Deleted Sparse Centroid Helpers & `ApplySegmentation` Class Name**:
   - Upstream PR `#450` inadvertently removed `sparse_mask`, `get_sparse_centroid`, `get_sparse_chunk_centroid`, and `sparse_split_indices` (called by `Segmentation.calculate_centroids()`) and renamed `ApplySegmentation` → `CellSegment` (imported by `slideflow/dataset.py:1494`).
   - **Fix**: Restored the sparse centroid functions (fixing a small-mask `step=0` `ZeroDivisionError` edge case and off-by-one final index truncation in `sparse_split_indices`) and preserved `ApplySegmentation` with `CellSegment = ApplySegmentation` alias.
2. **`**kwargs` Forwarding Bug in `save_zarr_compressed`**:
   - Fixed forwarding of named array `**kwargs` into `grp.create_dataset(...)`.
3. **Full Zarr v3 (`zarr >= 3.0`) `.zip` & `Segmentation.load()` Support**:
   - Added `_open_store()` and `load_zarr_arrays()` supporting both Zarr v2 and Zarr v3 `.zip` archives, updated `Segmentation.load()`, and guarded top-level `cellpose` imports in `slideflow/cellseg/__init__.py`.
4. **Added Regression Tests**:
   - Added `test_pr450_zarr_compressed_segmentation_and_outlines` testing positional + keyword Zarr `.zip` round-trips, `Segmentation.save(centroids=True)` / `Segmentation.load()`, and `fast_outlines_list()`.

## Audit Findings & Fixes Applied

1. **Rebased & Conflict-Resolved Onto Slideflow 3.1.0 (`slideflow/dataset.py`, `slideflow/model/features.py`)**:
   - Preserved `#466`'s `extract_tiles_from_tfrecords(dest: Optional[str] = None)`, `load_indices(verbose=False)`, and deadlock-safe `try ... finally` sentinel queue handling in `_FeatureGenerator`.
   - Removed duplicate `import glob` shadowing `from glob import glob` (`F811`), imported `nullcontext` explicitly (fixing `NameError: name 'contextlib' is not defined` when progress bars are unavailable), and normalized early-exit tuple returns (`return None, []`) in `_process_single_tfrecord_for_lower_mag`.
2. **`DualMagnificationFeatures` Bugs Fixed (`slideflow/model/features.py`)**:
   - **Wrong module path (`sf.io.tfrecord2idx`)**: Replaced non-existent `sf.io.tfrecord2idx.save_index` with `tfrecord2idx.save_index` (`slideflow.util.tfrecord2idx`).
   - **`IsADirectoryError` in `_save_concatenated_features` / `_load_concatenated_features`**: Saved/loaded `os.path.join(self.concatenated_dir, 'concatenated_features.pkl')` instead of opening the directory path itself.
   - **Base-Level WSI Pixel Coordinate Matching (`_find_spatial_matches`)**: TFRecord `loc_x, loc_y` coordinates are stored in level-0 WSI pixels rather than resized `low_mag_px` tile pixels. Estimated the actual WSI grid stride `(stride_x, stride_y)` from `high_coords` so spatial matching (`offset <= stride * mag_ratio / 2`) works across arbitrary WSI MPPs, `tile_px`, and `tile_um` settings.
   - **Device Auto-Selection & `kwargs` Isolation**: Replaced hardcoded `device='cuda'` default with `device: Optional[str] = None` (`get_device(device)`), avoided mutating `kwargs['device']` before forwarding `**kwargs` into `DatasetFeatures`, and fixed NumPy array truth-value ambiguity in `self.num_classes`.
3. **BatchNorm Running-Stats `NaN` Poisoning & CPU `autocast` Fixes (`slideflow/model/torch_utils.py`, `slideflow/model/torch.py`)**:
   - Upstream `Trainer._print_model_summary` and `SurvivalTrainer._print_model_summary` passed uninitialized `torch.empty(...)` tensors (which can contain `NaN`/`1e38` bytes from reused heap pages) through `print_module_summary` while the network was in `.train()` mode, corrupting `BatchNorm2d.running_mean` / `running_var` with `NaN`s that surfaced as soon as `.eval()` was invoked. Fixed by using `torch.zeros(...)` and running `print_module_summary` inside `module.eval()` + `torch.no_grad()`.
   - Disabled automatic `bfloat16` `autocast` on `device_type == 'cpu'` (matching `mps`) while preserving full CUDA FP16 mixed precision on GPUs.
4. **Convenience API & Verification**:
   - Added `Project.extract_lower_mag_tiles_from_tfr(...)` wrapper in `slideflow/project.py`.
   - Added `test_pr463_dual_magnification_extraction_and_features` in `scripts/ci/cpu_verification_suite.py` and CUDA dual-mag verification in `scripts/hpc/gpu_verification_suite.py`.
